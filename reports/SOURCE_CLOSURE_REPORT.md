## What counts as closure

1. **Matching metadata only:** if recovered records confirm the same dates and values, clarify the methods/provenance without fitting again.
2. **A demonstrated input correction:** if dated source evidence establishes different model input values or dates, preserve the current analysis, define the correction and identify all dependent fits, correlations, importance, diagnostics and figures before rerunning affected work. Do not imply a local sentence edit fixes a scientific input correction.
3. **Records unavailable:** retain precise unresolved-source qualifications and obtain the authors' scientific decision about the supported scope. Do not label the provenance gap resolved. A limitation statement is disclosure, not authentication.
