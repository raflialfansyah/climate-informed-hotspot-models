# Figures

`main/` contains eleven unchanged current manuscript PDF assets. Figure 1, the GADM-containing original map, is deliberately excluded from the public payload. `FIGURE_INDEX.json` records its status alongside the included figures. The manuscript's original map is preserved in the local before-edit archive and has not been replaced.

`python analysis/reproduce_figures.py` regenerates the eleven non-map main figures and seven regional diagnostic panels from packaged inputs. It skips Figure 1 when local geometry is absent. Set `HOTSPOT_COASTLINE_PATH` to an authorized local NPZ containing the recovered `coast` array to regenerate the original map design. No geometry is downloaded automatically. Outputs go to `generated/figures/`; `HOTSPOT_FIGURE_OUTPUT_ROOT` can override this location. Reference copies are never overwritten.

`supplementary/` retains workflow and regional diagnostic assets. The TikZ workflow needs a separate LaTeX environment. The two additional reference panels `national_annual_diagnostics` and `dry_wet_rmse_ratio` are not regenerated by this runner. No new model fitting or inference is required for these plots.

See `../docs/DATA_AVAILABILITY.md` for data and figure scope. GADM coordinate geometry is not part of this public package.
